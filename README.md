# Hello!

I am Renzo Scuadroni, and this is my resume repo, feel free to check it out hosted in github pages [here](https://ldevas.github.io/resume/)

Created using React + TypeScript + Vite

## Setup

Run `npm ci` to install dependencies.

## Run

In Conductor, use the **Run** action (default `dev`). The dev server starts with:

```bash
npm run dev -- --port "$CONDUCTOR_PORT" --strictPort
```

The app is served at `/resume/` (see `vite.config.ts` `base: '/resume'`).
